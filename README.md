# LIFT 1.0 — тренировки и динамика

Новый независимый PWA-проект. Содержит журнал тренировок OSFIT, календарь, импорт IRONLOG, цели, карту атлета, три режима тренировки и аналитический модуль «Динамика»: общее, силовые, тело, мышцы.

## Запуск

```bash
npm install
npm run build
npm run dev
```

## GitHub Pages

Создай новый публичный репозиторий `LIFT`, загрузив **содержимое** этого архива в корень. В Settings → Pages выбери GitHub Actions. В workflow настроена сборка и публикация. Не смешивай файлы со старым OSFIT.

## Данные

Данные остаются локально в IndexedDB. На новом адресе они **не переносятся автоматически**. Сначала экспортируй резервную копию из OSFIT, потом импортируй в LIFT. Имена внутренних хранилищ оставлены совместимыми для переноса.

## Статус

Сборка должна быть подтверждена командой `npm run build` локально или в GitHub Actions. Никаких обещаний полной проверки без запуска компилятора.
