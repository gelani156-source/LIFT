# LIFT 1.0 — тренировки и динамика

Новый независимый PWA-проект. Содержит журнал тренировок OSFIT, календарь, импорт IRONLOG, цели, карту атлета, три режима тренировки и аналитический модуль «Динамика»: общее, силовые, тело, мышцы.

## Запуск

```bash
npm install
npm run build
npm run dev
```

## GitHub Pages

Создай новый публичный репозиторий `LIFT`, загрузив **содержимое** этого архива в корень. В Settings → Pages выбери GitHub Actions. В workflow настроена сборка и публикация (`cancel-in-progress: false`, иначе возможна ошибка HTTP 400 «unfinished deployment»). Закоммитьте `package-lock.json` (создаётся после первого `npm install`) — тогда CI использует `npm ci`. Не смешивай файлы со старым OSFIT.

## Данные

Данные остаются локально в IndexedDB. Имена внутренних хранилищ (`osfit-db`, ключи `osfit-*`) оставлены совместимыми с OSFIT.

> ⚠️ **Один origin на GitHub Pages.** `https://<user>.github.io/OSFIT/` и `https://<user>.github.io/LIFT/` — это **один и тот же origin**, поэтому у них **общие** IndexedDB и localStorage. Если OSFIT и LIFT опубликованы под одним аккаунтом, LIFT сразу увидит данные OSFIT, а «Восстановить из JSON» в любом из приложений заменит данные в обоих. Перед импортом сделайте резервную копию (Настройки → Скачать архив JSON). Для полной изоляции опубликуйте LIFT на другом origin (другой аккаунт/организация или собственный домен).

## Статус

Сборка должна быть подтверждена командой `npm run build` локально или в GitHub Actions. Никаких обещаний полной проверки без запуска компилятора.


## Если на Pages «unfinished deployment» / HTTP 400
1. Settings → Pages → Source = **GitHub Actions**.
2. Actions → отмените зависшие запуски, дождитесь «Cancelled/Completed».
3. Запустите workflow заново (Run workflow). Новые запуски больше не отменяют идущий деплой.
