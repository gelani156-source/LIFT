# Проверки: блоки по 5 кг и мобильная вёрстка

## Сборка

```sh
npm ci
npm run build
npm run check:source
```

## Регрессионные тесты

- `node --test tests/local-coach.cjs tests/workout-date.cjs` — синтетические проверки локального тренера и дат. Два интервала тренера — скользящие 7 × 24 часа, не календарные недели; результаты не записываются в хранилище.

Запустите статический сервер из корня проекта (`python3 -m http.server 8000`).

- `/tests/block-weights.html` — 129 проверок реальных исходников: единицы нагрузки, перевод 1 блока в 5 кг, тоннаж, 1ПМ, аналитика, классификация мышц, сохранение исходных чисел и единиц при импорте/экспорте. Только тестовая страница загружает компилятор TypeScript 5.8.3 с CDN; приложению сеть для этого не нужна. Результат доступен в `window.blockWeightTestResult`.
- `/tests/mobile-layout.html` — стресс-сценарии вёрстки. Установите ширину viewport 320, 375, 390, 430 и 700 px, вызовите `runMobileLayoutChecks()` в консоли. Страница использует реальные CSS, а также извлекает актуальный `OSFIT_CSS` из App.tsx и применяет его после внешних стилей. Результат выводится на странице. Проверяет отсутствие переполнения, целые подписи переключателя и работоспособность горизонтальной прокрутки фильтров аналитики.

## Правила совместимости данных

- Без поля `weightUnit` только точные старые названия «Трицепс» и «Сгибания» означают блоки по 5 кг. Похожие и полные названия автоматически не конвертируются.
- `weightUnit: "kg"` или `"blocks"` имеет приоритет. Выбор единиц в редакторе меняет интерпретацию введённых чисел; сами числа не переписываются.
- В старых записях не меняются ID, названия и исходные веса. Отображаются уточнённые названия; тоннаж пересчитывается при чтении, без перезаписи базы.
- Пример: 6 блоков × 10 повторов = 30 кг × 10 = 300 кг тоннажа.
- Вес тренажёра считается по условию 5 кг за блок, без оценки передаточного отношения тросов.

Перед публикацией рекомендуется скачать архив JSON в настройках рабочего приложения. Тестировать импорт/восстановление лучше на отдельном origin: LIFT и OSFIT под одним аккаунтом GitHub Pages используют общее хранилище.
