# LIFT 2.0 — состояние исходников

Сборка для проверки в Codespaces. НЕ маркируется как проверенный финальный релиз.

Проверено в текущей среде:
- Проверка структуры файлов и локальных импортов: успешно (`node verify-source.cjs`).
- Синтаксическая проверка TypeScript/TSX через TypeScript transpileModule: успешно.
- ZIP целостность: проверяется при упаковке.

НЕ ПРОВЕРЕНО:
- `npm run build`: зависимостей нет, офлайн-установка выдаёт `ENOTCACHED` для @types/node.
- Автоматические тесты всех пользовательских сценариев и Safari/iOS.
- Соответствие анатомической модели всем художественным референсам.

Изменения этой редакции по сравнению с предыдущим кандидатом:
- 6 периодов в Динамике (7д/30д/3м/6м/1г/всё).
- Сравнение тоннажа текущего периода с предыдущим равным периодом.
- Линии силовых целей на графиках для выбранного упражнения и соответствующей метрики.
- Передача целей из App в Динамику без дублирования настройки режима тренировок.

Проверить в Codespaces:
1. `npm install`
2. `npm run build`
3. `npm run dev` и ручные сценарии из ТЗ.

Рабочий сайт не перезаписывать до успешной сборки и резервной копии данных.
