## Найденные проблемы (исправлены)
**Белый экран**
1. Нет ErrorBoundary — любая ошибка отрисовки = пустая страница. → добавлен экран восстановления + таймер-страховка в index.html.
2. `localStorage` без try/catch (приватный режим, блок cookie) → белый экран при старте. → `storage.ts`.
3. Повреждённый черновик тренировки / запись без `sets` в IndexedDB → падение при каждом запуске. → санитайзеры при чтении (`db.ts`, `readDraft`).
4. `crypto.randomUUID` недоступен по http (dev по IP) и в старых iOS. → fallback в `uid()`.
5. SW в dev кэшировал модули Vite. → регистрация только в production.
6. После деплоя GitHub Pages может отдать устаревший index.html (max-age=600) со ссылками на удалённые файлы. → навигация с `cache:'no-cache'`.

**GitHub Pages / PWA**
7. `cancel-in-progress: true` — вероятная причина HTTP 400 «unfinished deployment» (отменённый деплой остаётся незавершённым). → `false`, таймауты, `configure-pages`, `npm ci` при наличии lock-файла, имя workflow «Deploy LIFT».
8. SW удалял ВСЕ кэши origin (общий github.io с OSFIT). → удаляются только `lift-*`.
9. Нет предзагрузки: офлайн-запуск после первого визита не работал. → precache оболочки (проверено).
10. Манифест только с SVG; iOS не берёт SVG. → PNG 192/512/maskable/apple-touch-icon, iOS-метатеги, safe-area.
11. Внешний Google Fonts `@import` (блокировал рендер, нарушал «офлайн/без внешних запросов», стоял не в начале CSS). → удалён.
12. Один origin с OSFIT → общие IndexedDB/localStorage. Имена оставлены (совместимость), риск описан в README/инструкции.

**Данные (IndexedDB)**
13. Импорт копии: `clear()` + необработанное исключение → возможная потеря всех данных при некорректной записи (замеры/расписание не валидировались). → нормализация + откат транзакции.
14. Запрос `navigator.storage.persist()` (защита от вытеснения в Safari).
15. «Последняя копия» помечалась до успеха экспорта.

**Расчёты**
16. 1ПМ: три разных правила (Динамика / история / рекорды / цели; 1 повтор давал 1,033×вес; без лимита повторений). → единая `estimate1RM`: 1 повтор = вес, 2–12 Эпли, >12 не считается.
17. Тоннаж: История включала разминки, Динамика — нет. → единая `volumeOf` (рабочие выполненные подходы).
18. Разминка могла давать «рекорд». → исключена.
19. Классификация мышц не понимала «ё»: **«Жим штанги лёжа» не давал нагрузки на грудь** (и «наклонная скамья», кроссовер, бабочка). → нормализация ё/е и новые правила; гиперэкстензия → спина/ягодицы.
20. Даты в UTC: тренировки/замеры утром в UTC+ попадали на вчера (Календарь, замеры); подписи недель в Динамике — воскресенье вместо понедельника. → локальные даты.
21. Импорт IRONLOG: подходы без флага `done` давали нулевой тоннаж. → для истории по умолчанию выполнены.

**Интерфейс / мобильный**
22. Тема применялась только после открытия «Настроек» (на старте всегда тёмная). → применяется при запуске и до отрисовки.
23. Порядок CSS (theme перед style) и фон `html` — тема не перекрывала базу. → порядок исправлен.
24. Динамика в светлой теме: переменные `--surface*`/`--text` не были определены → тёмные плитки. → алиасы.
25. Кнопки метрик «Силовые» схлопывались (текст друг на друге). → `flex:0 0 auto`.
26. Поля RPE/RIR/темп 11px → iOS Safari зумит страницу. → 16px на touch.
27. Поле веса/повторов: залипающий «0» (нельзя очистить). → пустое при 0.
28. Две разные реализации атлета (App.tsx и MuscleMap.tsx). → единый компонент.

## Остаточные риски (не менялось)
- Ось X графиков — по порядку точек, а не по времени.
- `window.prompt` для замены упражнения (работает, но не нативный UX).
- Эффект достижения целей вызывает setState внутри updater (работает, но нечисто).
- Классификация упражнений — эвристика по названию; для нестандартных названий нагрузка не считается.
- Эвикция данных Safari для сайтов, не добавленных на экран «Домой»: делайте резервные копии.
