LIFT 1.0 — НОВЫЙ РЕПОЗИТОРИЙ

1. Сохрани старый OSFIT без изменений и экспортируй резервную копию его данных в JSON.
2. На GitHub создай НОВЫЙ репозиторий LIFT (Public).
3. В Codespaces или VS Code распакуй СОДЕРЖИМОЕ архива в корень LIFT.
4. Открой терминал, выполни npm install, затем npm run build.
5. Убедись, что сборка прошла без ошибок.
6. Сделай Commit + Push. В Settings > Pages выбери GitHub Actions.
7. На опубликованном сайте проверь вкладки, тренировку, импорт, Динамику и сохранение данных.
8. Импортируй резервную копию OSFIT в новый LIFT.

ВНИМАНИЕ: если OSFIT и LIFT лежат на одном github.io-аккаунте, у них ОБЩАЯ база данных браузера (один origin). Не импортируйте копию «поверх», не сделав свежий экспорт. После обновления закоммитьте package-lock.json.

Не копируй старые файлы OSFIT в LIFT. Папку .git нового репозитория не удаляй. node_modules и dist в репозиторий не добавляй.
