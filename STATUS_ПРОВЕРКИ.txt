LIFT — технический базис для разработки LIFT 2.0 (НЕ финальный релиз 2.0)

Основа: LIFT_FIXED.zip, предоставленный пользователем и исправленный Claude.
Правка: единственный переключатель режима на экране активной тренировки; название третьего режима — «Расширенный». В настройках переключатель не добавлялся.

ПРОВЕРЕНО:
- ZIP и наличие требуемых исходников
- локальные импорты
- синтаксическая транспиляция 13 исходников TypeScript/TSX: 0 диагностик

НЕ ПОДТВЕРЖДЕНО:
- npm run build и полная строгая проверка типов: npm install заблокирован DNS EAI_AGAIN registry.npmjs.org
- тесты в Safari/iPhone
- соответствие всем утверждённым пунктам LIFT 2.0

ВАЖНО: в этом пакете ещё не создан новый анатомически детализированный атлет и не завершена аналитика 2.0. НЕ ЗАМЕНЯЙТЕ им опубликованное рабочее приложение, если рассчитываете получить готовый LIFT 2.0.
