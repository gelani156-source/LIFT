# LIFT 2.0 — release candidate (исходный проект)

Основа — LIFT_FIXED.zip от Claude, включая защиту данных, PWA, ошибки запуска и единую оценку 1ПМ.

В этой сборке: 6 периодов в «Динамике» (7д, 30д, 3м, 6м, 1г, всё), графики по фактическим датам, частота тренировок по неделям, экспорт графика в SVG, детализация SVG-модели мышц, один переключатель режима тренировки на экране занятия.

**Ограничения:** новая анатомическая модель всё ещё представляет собой доработанный SVG, а не фотореалистичный отдельный профессиональный атлас; достижения, сравнение периодов, все 48 критериев ТЗ и полный iPhone QA не подтверждены. Не выдавать за полностью принятый релиз без проверки.

**Проверка в Codespaces:** `npm install && npm run build`, затем `npm run dev`. Проверьте импорт, резервные копии и данные на копии.
